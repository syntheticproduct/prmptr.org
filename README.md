# prmptr.org

> A minimal editor for prompt engineering.

Building this — a Tauri + Next.js desktop app that treats
Claude-style markdown prompts as first-class citizens: XML tags,
structured prompting patterns, run-against-Claude inline.

The thesis: *"VS Code is to software engineers what nothing is to
prompt engineers — yet."*

Status: in early development. Public code drop coming.
