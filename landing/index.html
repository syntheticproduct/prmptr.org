Why

The tooling for writing long, structured LLM prompts is bad. You either live in a textarea and squint at raw markdown, or use a general-purpose editor that doesn't know prompts have headings, XML tags, and structure that matters.

prmptr is what an editor built specifically for prompts looks like.

XML tags, first-class

<system>, <examples>, <instructions> render as inline pills — not raw text and not stripped. Visual structure, preserved source.

Byte-perfect round-trip

Open a prompt, edit one paragraph, save — nothing else moves. No list-marker normalization, no table padding shifts. Diffs stay clean.

Native desktop

~5 MB binary built in Rust + Tauri. Real file picker, real filesystem, real OS clipboard. Not another tab in your browser.

Built for Claude

Designed around Anthropic's prompting best practices: clear role, structured instructions, XML-tagged examples. The affordances follow the doctrine.

Get it

Download the latest installer or the bare executable from GitHub Releases . The installer adds prmptr to "Open with…" for .md files. The bare .exe is a portable single-file download — double-click to run.

Building from source: 

git clone https://github.com/syntheticproduct/prmptr.org
cd prmptr.org
npm install
npm run tauri dev
